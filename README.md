# Reinos de Etherial

MMORPG 2D pixel-art para navegador, construido desde cero.

## Estado
Fase 1: núcleo jugable.

## Objetivo
Un mundo persistente con clases, habilidades, caza, misiones, mapas, inventario, equipo, tiendas, bosses y multijugador. Telegram Mini App y economía P2E se integrarán únicamente después de asegurar la lógica autoritativa del servidor.

## Desarrollo
- Frontend: HTML5 Canvas + JavaScript
- Backend previsto: Node.js
- Persistencia prevista: PostgreSQL
- Desktop y móvil
