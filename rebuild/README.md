# Reinos de Etherial — Phaser Rebuild

Nueva reconstrucción del MMORPG en Phaser/WebGL.

## Estado actual
- Escena Lumen 1280x720
- Movimiento WASD/flechas
- Cámara y físicas
- Colisiones con edificios
- Profundidad dinámica
- NPCs: Aldric, Mira, Borin y Selene
- Interacción con tecla E y diálogos
- HUD MMORPG inicial
- Base separada del prototipo anterior

## Ejecutar
Sirve la carpeta `rebuild/` con un servidor HTTP local. El punto de entrada es `rebuild/index.html`.

## Dirección
Fantasía medieval 2D/2.5D con arte original prerenderizado y presentación inspirada en MMORPG clásicos de gran escala.
